# Language Tutor

Kyle's home base for language learning, maintained by Lang, his AI language tutor.

**Current language:** Japanese 🇯🇵

## Where things are

| Path | What's there |
|---|---|
| [`INSTRUCTIONS.md`](INSTRUCTIONS.md) | Kyle's standing instructions for how the tutor works |
| [`tutor-notes/`](tutor-notes/) | The tutor's working memory: learner profile, progress, vocab and grammar seen |
| [`japanese/curriculum.md`](japanese/curriculum.md) | The Japanese learning plan |
| [`japanese/daily/`](japanese/daily/) | Daily lessons: comprehensible-input videos plus exercises, one file per day |

## How to use it

1. Open today's file in `japanese/daily/` (named `YYYY-MM-DD.md`).
2. Watch the videos, then work through the exercises.
3. Tell Lang how it went (what was easy, what was hard). That feedback shapes the next lesson.
