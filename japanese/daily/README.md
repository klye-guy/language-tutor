# Daily lessons

One file per day, named `YYYY-MM-DD.md`. Each has:

1. **Videos:** comprehensible-input YouTube videos at the right level, with links.
2. **Before you watch:** a few key words to listen for.
3. **Exercises:** comprehension checks, shadowing, and speaking prompts tied to each video.
4. **Read it:** a small survival-reading piece tied to the day's topic.
5. **Use it today:** one or two phrases to try out loud.
